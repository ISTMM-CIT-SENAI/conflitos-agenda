# Sem e-mail: Colaborador só com nome completo e login por usuário e senha

Para reduzir o tratamento de dados pessoais (LGPD), o sistema não guarda e-mail nem outros contatos: o Colaborador é identificado apenas pelo nome completo, e o acesso é feito com nome de usuário e senha. A decisão veio da chefia do setor.

## Consequências

- Não existe recuperação de senha por e-mail: o Administrador define uma senha temporária, que precisa ser trocada no próximo login.
- O sistema não envia notificações (por exemplo, "sua solicitação foi aprovada"). Para adicioná-las no futuro, seria preciso um novo canal de contato e uma nova avaliação de LGPD.
- O nome de usuário continua sendo dado pessoal quando identifica alguém; as senhas são guardadas apenas como hash.
